神戸・元町駅より徒歩7分の場所に、**ONE COIN コワーキング** を10月下旬にオープンいたします。

## ご利用料金

神戸市内のコワーキングスペースは、月額会員制や時間課金制が多く、短時間のご利用でも1,000円前後となる場合があります。

当店では **入場料500円・時間無制限** とし、1時間のご利用でも終日のご利用でも同一料金となっております。

## 所在地

[兵庫県神戸市中央区中山手通4丁目10-31](/#information)（元町駅徒歩7分）

元町駅より鯉川筋沿いを北へ進んでいただき、コープ山手様の隣に位置しております。

## 運営体制

無人運営・会員登録不要の体制により、料金を低く抑えております。ご入店後、左側に設置のタブレットより決済いただくだけで、すぐにご利用いただけます。

| 項目 | 内容 |
| --- | --- |
| 料金 | 入場料500円（時間無制限） |
| 会員登録 | 不要 |
| 決済 | キャッシュレスのみ |
| 営業 | 24時間 |
| 席数 | 20〜30席（予定） |

## 設備

- 無線LAN（Wi-Fi）
- 電源コンセント
- カウンター席・テーブル席
- 飲食物の持込（可）
- 会話（可）

## ご利用の流れ

1. ご入店後、左側のタブレットにて入場料500円の決済を行ってください
2. 空席にて作業・休息等にお過ごしください
3. ご退店の際、テーブルに汚れがある場合は清拭にご協力ください

無人運営のため、ご退店時の清掃にご協力をお願いいたします。詳細は [ご利用方法](/#howToUse) をご参照ください。

## こんな方におすすめ

- 神戸で格安に作業できるコワーキングを探している方
- 元町・三宮周辺でドロップインしたい方
- カフェより電源とWi-Fiを安定して使いたい方
- 会員登録や月額契約をしたくない方
- 夜間や早朝など、24時間いつでも使いたい方

仕事、勉強、ちょっとした休憩まで、目的を問わずご利用いただけます。

## オープン予定

10月下旬のオープンを予定しております。ご予約は不要でご利用いただけます。
